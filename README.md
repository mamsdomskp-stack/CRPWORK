# Voter Mobile Link Instant Clone

Deploy-ready standalone frontend clone based on the supplied HTML source.

## Features
- Responsive dark/neon UI
- Dashboard statistics
- 3-server single selection
- EPIC validation
- 10-digit mobile validation
- Processing state
- Success/reference popup
- Local transaction history
- Browser localStorage persistence
- GitHub Pages / Vercel / Netlify compatible

## Important
This is a frontend clone. The supplied HTML does not include the original server-side PHP/database implementation, so this project does not perform real voter-record linking. Requests are stored locally in the browser for demo/testing purposes.

## Deploy
Open `index.html` directly, or deploy the repository as a static site. No build command is required.
